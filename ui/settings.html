外部服務

填了之後，日誌裡的 MR 與議題連結會先在 app 裡顯示內容，不用跳去瀏覽器。

GitLab

Redmine

token 是機密，只存在本機的 settings.json（路徑就是下面「app 自己的檔案」那一行）， 不會寫進日誌資料夾，存好之後也不會再顯示出來。token 欄留空表示不更動原本那把。

日誌規則

日誌檔不是這個 app 寫的，是 Claude Code 照這份規則寫的。按「套用到 Claude」會把它寫進 的「# 每日工作日誌」那一段， Claude Code 之後就會照新的寫法記。

這會動到你的 Claude 全域設定檔。 只會取代「# 每日工作日誌」那一段，其他內容一個字都不動；而且寫之前一定先把整個檔備份一份。

這份規則是寫給 Claude 看的，app 不會照它改變解析行為—— 解析規則寫死在 src-tauri/src/parser.rs，兩邊要人工保持一致。
